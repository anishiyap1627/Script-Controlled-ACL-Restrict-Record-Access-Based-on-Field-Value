1. Brainstorming & Ideation

Project Title
   Script-Controlled ACL – Restrict Record Access Based on Field Value

Problem Statement
   In ServiceNow, users may have access to records that they are not authorized to view. A mechanism is required to restrict record access based on specific field values and user roles.

Proposed Solution
   Implement a script-controlled Access Control List (ACL) to restrict users from viewing records based on the Branch field.

Key Idea
   Only users with the required role and belonging to the EEE branch can view the permitted records, while administrators retain full access.

Technologies Used
- ServiceNow
- Access Control List (ACL)
- Server-side Scripting
- Custom Roles
