 2. Requirement Analysis

Functional Requirements

- Create users and custom roles in ServiceNow.
- Create the required institution details table.
- Configure ACLs for different operations.
- Restrict record access based on the Branch field.
- Allow authorized EEE branch users to view permitted records.
- Allow administrators to retain full access.

Non-Functional Requirements

- The system should provide secure record access.
- ACL rules should work consistently.
- Unauthorized users should not be able to access restricted records.
- The solution should be easy to maintain and test.

User Roles

- bb1 – User role
- bb2 – Custom role
- Admin – Administrator with full access

Software Requirements

- ServiceNow Developer Instance
- Web Browser
- Internet Connection

Technical Requirements

- ServiceNow ACL
- Server-side scripting
- Custom table
- Custom roles
