4. Project Planning Phase

Project Plan:

The project is planned and implemented in the following stages:

1. Create users and custom roles.
2. Create the required institution details table.
3. Configure the Read ACL.
4. Configure the Create ACL.
5. Configure the Write ACL.
6. Configure the Delete ACL.
7. Test access using different user roles.
8. Verify the final output and document the project.

Resources Required:

- ServiceNow Developer Instance
- Administrator access
- Custom users and roles
- Institution details table
- ACL configuration
- Server-side scripting

Testing Plan:

The ACLs will be tested using users with different roles to verify that authorized users can access the required records and unauthorized users are restricted.

Expected Outcome:

The system should securely control record access according to the defined roles and Branch field conditions.
