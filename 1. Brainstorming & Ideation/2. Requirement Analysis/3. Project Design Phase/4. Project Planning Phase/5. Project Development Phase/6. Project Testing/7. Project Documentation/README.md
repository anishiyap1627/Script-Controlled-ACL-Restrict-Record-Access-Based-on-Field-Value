7. Project Documentation

Project Title:

Script-Controlled ACL – Restrict Record Access Based on Field Value

Project Objective:

To control access to ServiceNow records based on user roles and field values using Access Control Lists (ACLs).

Technologies Used:

- ServiceNow
- ACL
- Server-side Scripting
- Custom Roles
- Custom Table

Project Modules:

- User and Role Creation
- Table Creation
- Read ACL
- Create ACL
- Write ACL
- Delete ACL
- Testing

Project Outcome:

The project successfully implements role-based and field-based record access control in ServiceNow. Unauthorized users are restricted from accessing protected records.

Conclusion:

The Script-Controlled ACL project provides a simple and effective way to control record access in ServiceNow based on user roles and field values.
